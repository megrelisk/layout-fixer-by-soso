# LayoutFixer - автоисправление раскладки (EN / RU / KA)

Программа для Windows, которая сидит в трее и следит за тем, что вы печатаете.
Если слово набрано не в той раскладке, она стирает его, пишет правильно и
переключает раскладку сама.

| Вы набрали | Раскладка была | Станет |
|---|---|---|
| `gamarjoba` | английская | `გამარჯობა` |
| `пфьфкощиф` | русская | `გამარჯობა` |
| `ghbdtn` | английская | `привет` |
| `ჰელლო` | грузинская | `hello` |

Проверка происходит, когда слово закончено: после пробела, Enter или Tab.

Ещё программа исправляет случайно включённый Caps Lock: `hELLO` станет
`Hello`, а Caps Lock выключится. Это работает и вместе со сменой раскладки:
`gHBDTN` станет `Привет`.

## Установка

1. Скачайте `LayoutFixer.exe` из раздела **Releases** этого репозитория
   (релиз `latest` обновляется при каждом изменении в `main`).
2. Положите его в постоянное место, например `C:\Programs\LayoutFixer\`.
3. Запустите. В трее появится синяя иконка с буквой «ა».

При первом запуске программа сама прописывает себя в автозагрузку Windows.
Отключить это можно в меню иконки: «Запускать вместе с Windows».

В Windows должны быть добавлены все три раскладки: English, Русский и
ქართული (Georgian QWERTY или любая другая грузинская). Программа читает
раскладки прямо из системы.

## Управление

- **Pause/Break** сразу после исправления отменяет его и запоминает слово, чтобы
  больше его не трогать.
- **Pause/Break** посреди слова (или сразу после него) переводит слово в
  следующую раскладку вручную.
- Левый клик по иконке открывает статистику.
- Правый клик: сколько времени сэкономлено, статистика, включение и выключение
  автоисправления и исправления Caps Lock, автозапуск, список исключений, выход.

## Статистика

Программа считает исправления по дням (раскладка, Caps Lock, вручную через
Pause, отменённые) и примерно оценивает, сколько секунд они сэкономили. Для
каждого исправления берётся время, которое ушло бы на ручное исправление:

- заметить ошибку: 1,5 с;
- стереть слово Backspace: 0,12 с на символ;
- переключить раскладку: 1 с (для Caps Lock: нажать Caps Lock, 0,5 с);
- набрать слово заново с вашей скоростью набора, которую программа измеряет,
  пока вы печатаете.

Если исправление отменено через Pause, его секунды вычитаются. Оценка грубая
и скорее заниженная: на практике ошибку часто замечают только через несколько
слов, и стирать приходится больше.

Настройки, исключения, статистика (`stats.json`) и журнал лежат в
`%APPDATA%\LayoutFixer`. В статистике хранятся исправленные слова, она
никуда не отправляется.

## Как это устроено

- `app.py` ставит низкоуровневый хук клавиатуры (`WH_KEYBOARD_LL`) и
  запоминает физические клавиши текущего слова.
- На границе слова `engine.py` прочитывает те же клавиши во всех трёх
  раскладках и ищет каждый вариант в словаре. Если на экране не слово (или
  очень редкое слово), а в другой раскладке получается частое слово, текст
  заменяется через `SendInput`, а раскладка переключается.
- Словари: Hunspell (en_US, ru_RU, ka_GE) плюс частотные списки, источники в
  `dict_src/SOURCES.md`. `build_dicts.py` разворачивает их во все словоформы
  и сохраняет как отсортированные хеши, поэтому проверка слова занимает
  микросекунды.

## Сборка из исходников

```
pip install -r requirements.txt spylls pytest pyinstaller
python build_dicts.py
python -m pytest tests
python tools/evaluate.py          # точность на симуляции
pyinstaller --onefile --noconsole --name LayoutFixer --add-data "dicts;dicts" --hidden-import pystray._win32 app.py
```

Запуск без сборки: `pythonw app.py`.
